# Changelog

All notable changes to Research Copilot will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2024-XX-XX

### Added
- Initial release
- PDF text extraction using PDF.js
- Image extraction from PDFs
- OCR support using Tesseract.js
- TF-IDF based document search
- `@research` chat participant for Copilot Chat
- Language Model Tools for document querying
- Visual dashboard with search and statistics
- Document tree view in Explorer
- Auto-indexing of PDFs in workspace
- Export notes to Markdown
- Configurable settings for indexing behavior

### Coming Soon
- Vector embeddings for semantic search
- Citation extraction
- Annotation support
